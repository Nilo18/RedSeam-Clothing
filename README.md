# Overview
This is an online e-commerce website that enables extensive product browsing through filtering and sorting features.

Developed as an entry demo for the Redberry Fullstack Development Bootcamp, the project provides a frontend interface connecting to the company’s existing backend.

# Tech Stack
- Frontend: Angular + TypeScript

# Key Features
- Product filtering and sorting  
- User authorization and authentication  
- Checkout simulation  
- Responsive UI optimized for multiple devices
